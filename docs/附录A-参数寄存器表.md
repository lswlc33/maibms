# 附录 A：参数寄存器全表

| 项目 | 说明 |
|---|---|
| 数据宽度 | 全部 2 字节 u16，**小端** |
| 读参数 | 功能码 `02`，寄存器=起始地址，长度=读取字节数 |
| 写参数 | 功能码 `22`，寄存器=本表地址，数据=值小端 |
| 生效 | 写完后需发 `51/07`（保存应用参数）写 flash |
| 倍率 | 工程量 = 原始值 ÷ 倍率 |
| 名称标注 | 带 **※** 的参数名来自新版 App 或厂家参数页；旧版主参数表无此参数 |
| 符号 | 温度类（56 ~ 98 等）按 **s16** 读：`FE FF` = −2 ℃，当无符号读会得到 65534 |
| 宽度 | 容量类是 **u32 跨两个寄存器**（低字 @addr、高字 @addr+2，倍率 1e6）：162/164 物理容量、166/168 剩余容量、170/172 循环容量。`0x22` 一次只写 2 字节，改这类参数要**连写两帧** |
| 未披露 | 权限不足时整块读回 `0xFFFF`（真机实测：一级权限读保护参数区全部 FFFF）。解析时视为「无数据」显示 `--`，不要当 65535 或 65534 呈现给用户 |
| **实测覆盖** | 2026-09-29 真机读回 **157 项**，覆盖地址 `0~50`、`56~98`、`104~138`、`140~150`、`152~196`、`298~328` 以及身份区 `262/528/576/620/636`：**地址与倍率全部吻合**（读数参见 [第 6.9 节](06-参数读写.md#69-真机实测补充2026-09-29antble24cbub-3547--固件-24cbub02-240623c)）。未实测：`198~296` 内阻/电池 ID、`330~385` 密码区（实现上刻意不读）、`406` 之后 |

## A.10 新版命令码写法

新版参数表把「功能码 + 寄存器」写成 4 位命令码，例如 `5107` = 功能码 `51` + 寄存器 `07`：

| 命令码 | 功能码 | 寄存器 | 含义 |
|---|---|---|---|
| 2301 | 0x17 | 0x01 | 写入一级权限密码 |
| 2302 | 0x17 | 0x02 | 写入二级权限密码 |
| 2303 | 0x17 | 0x03 | 写入三级权限密码 |
