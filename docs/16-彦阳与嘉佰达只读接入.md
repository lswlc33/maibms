# 彦阳 / 嘉佰达保护板只读接入

这两类设备直接连接保护板，不经过电量计。接入覆盖公共协议引擎、Android / iOS / Web Bluetooth 传输、竖屏仪表盘、横屏仪表与只读参数页。原有蚂蚁保护板的参数修改功能保留；彦阳和嘉佰达的接入只允许读取。

## 支持范围

| 板型 | 协议与 BLE | 仪表数据 | 只读参数 |
| --- | --- | --- | --- |
| 彦阳 YYBMS B 代 | Modbus 风格 FC03；FFE0 / FFE2 写 / FFE1 通知；另支持 FEE9 模块 | 总电压、电流、功率、SOC、容量、循环、单体、温度、MOS、均衡、状态与保护；具体以设备实际返回字段为准 | 设备信息，以及可直接读取的保护阈值、均衡参数 |
| 嘉佰达 JBD 经典协议 | DD / A5 读命令；FF00 / FF02 写 / FF01 通知；兼容 FFE0 透传模块 | 总电压、电流、功率、SOC、容量、循环、单体、NTC 温度、MOS、均衡与保护位 | 型号、版本、生产日期、串数、温度探头数、额定容量等直接可读信息 |

没有实际读到的数据不会用默认的 0 代替；没有能力或没有数据的行、灯、卡片按需隐藏。实际的 0% / 0 A / 0 次属于有效读数。断线后最后读数保留，页面明确标注时效。快照保存板型、能力和只读参数，预览不会套用上一台设备的界面。

扫描先按名称和广播服务给出候选。广播名可由厂家改写，通用 FFE0 服务也不代表某个品牌；自动识别不到时，在扫描页先选择“彦阳”或“嘉佰达”，再选择对应设备。板型随设备档案保存，后续重连沿用。彦阳必须通过协议签名检查，嘉佰达必须返回校验正确的 DD 报文。

## 只读边界

- 彦阳仅允许 FC03 的五个已知块：`63/4`、`1/79`、`80/80`、`160/81`、`240/20`。不发送 FC11、开关控制、校准、重启或储运命令。
- 嘉佰达的数据读取仅允许 `DD A5 03`、`DD A5 04`、`DD A5 05`。用户明确提供已有密码和真实模块 MAC 时，另允许 `FF AA 15/17/18` 完成本次连接的蓝牙模块登录；不自动猜密码，不发送 `16` 改密码或 `1D` 厂商提权命令。不发送 `DD 5A`，不进入工厂模式，不修改 EEPROM、MOS、SOC 或密码。
- 经典嘉佰达读取 EEPROM 保护阈值需要先写 `56 78` 进入工厂模式，故本实现不读取这一部分。不会在页面上套用蚂蚁保护参数表。新 V11 的 FA 参数读取扩展缺少足够的独立实现和样本，本次不启用。
- 应用页面、仓库命令入口和三端传输都按板型拦截不适用的修改命令。BLE 的 GATT write 只用于发送上述读取请求，不等于修改保护板设置。

## 字段与报文取舍

### 彦阳

读取请求使用 CRC16-MODBUS（初值 FFFF，多项式 A001，低字节在前），应答按长度重组通知并校验，不能依赖 MTU 或单次通知边界。

| 用途 | 请求十六进制 |
| --- | --- |
| B 代签名 | `01 03 00 3F 00 04 74 05` |
| 基础与电压电流 | `01 03 00 01 00 4F 55 FE` |
| 状态、单体与容量 | `01 03 00 50 00 50 45 E7` |
| 参数阈值 | `01 03 00 A0 00 51 84 14` |
| 扩展身份 | `01 03 00 F0 00 14 45 F6` |

B 代签名为小端 `0x4D444253`，同时核对基础块偏移 124。只支持已确认的 B 代布局；A 代、继电器型 0x1000 寄存器族和未确认的 HB/O2 热敏变体不套用 B 代解析，给出不兼容说明。

总压为基础块偏移 150 的 mV，电流为偏移 154 的 0.01 A。两个开源实现的电流符号存在冲突，方向以状态字 bit26..27 为准，并归一为本项目的“放电正、充电负”。温度普通变体按 raw−40℃，无效哨兵不显示为温度；单体保持原始串号。学习容量、累计能量及生产日期等来源存在冲突或单位未确认的字段不展示。

### 嘉佰达

请求为 `DD A5 reg 00 checksumHi checksumLo 77`；读 03、04、05 的校验分别为 FFFD、FFFC、FFFB。响应的校验覆盖 **status + length + payload**，不包含响应寄存器，不能把请求与响应校验范围混用。按头部长度拼包，不能搜索第一个 77 作为帧尾（数据本身可以含 77）。

03 帧的电流是有符号大端数，JBD 放电为负，转换到本项目时取反；MOS 状态最高位声明电流和容量使用 0.1 还是 0.01 单位。NTC 为 `(raw−2731)/10℃`。均衡位图和单体电压分别在 03、04 帧，合并时保留位图，避免下一帧单体刷新把均衡绿点清掉。05 型号是直接的 ASCII 文本，没有额外长度前缀。

部分 JBD 蓝牙模块需要密码登录。在“只读参数 → 蓝牙访问”输入已有 6 位字符密码与真实模块 MAC 后，可使用 `FF AA 15/17/18` 会话认证；凭据只存本机，登录数据不进入帧日志。iOS 和 Web 不暴露真实 MAC，需从模块标签或原厂 App 手动取得。另一些新版模块要求系统蓝牙 passkey 配对，配对后直接回应 DD 读取；这类模块不使用旧 FFAA 登录。认证被拒绝或未应答时停止该次登录，不反复猜测。需要厂商提权或加密私有协议的设备仍可能无法读取。连接时应关闭占用这块板的其他 App。
