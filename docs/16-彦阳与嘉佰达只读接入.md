# 彦阳 / 嘉佰达 / 极空保护板只读接入

新增保护板直接连接板上的 BLE，不经过电量计。蓝宝保持电量计身份，读取其自测数据和中继信息。公共协议、Android / iOS / Web Bluetooth、竖屏仪表、横屏仪表和只读参数页共用板型与字段能力规则。

## 支持范围

| 设备 | 通信 | 当前读取范围 |
| --- | --- | --- |
| 彦阳 YYBMS B 代 | FC03；FFE0 / FFE2 写 / FFE1 通知；FFE1 同特征收发兜底；FEE9 的 D44BC439/FEE1 与 8EC90001/8EC90002 模块 | 总压、电流、功率、SOC、容量、循环、单体、普通变体温度、MOS、均衡、运行状态和保护；可直接读取的设备信息与阈值 |
| 彦阳旧 A 兼容布局 | FC03；先尝试地址 1，再允许地址发现 `0/1`，读取旧 A 基础/扩展/状态块 | 有来源映射的总压、单体、原始电流和温度；不转换 SOC、容量、MOS、循环或电流方向；合成边界测试通过，实物仍待验证 |
| 嘉佰达 JBD 经典 BLE | DD A5 03/04/05；FF00 / FF02 写 / FF01 通知；FFE0 / FFE1 透传模块 | 总压、电流、SOC、容量、循环、单体、NTC、MOS、均衡、保护和型号；已有密码可用于本次连接登录 |
| 极空 JK02 24S / 32S | FFE0 / FFE1；20 字节 AA5590EB 请求；300 字节 55AAEB90 应答 | 按设备信息和实时报文确认 JK02 布局，读取总压、电流、SOC、SOH、容量、循环、单体、有效温度、MOS、均衡和保护 |
| 极空 JK04 浮点均衡板 | 与 JK 相同的 97/96 请求；真实 JK04 设备信息与实时浮点单体报文 | 显示有效浮点单体、由单体求和的总压、均衡与运行时间；该报文没有总电流、SOC、容量、MOS 或温度；设备和固件覆盖仍有限 |
| 蓝宝电量计 | 既有 FFE0 / FFE2 写 / FFE1 通知，FA50 双表与私有 CRC | 自测电压、电流、功率、SOC、温度、容量、循环、单体极值及被中继保护板信息；没有逐串网格、MOS 或 SOH |

字段没有返回时不以默认 0 代替；真实 0% / 0 A / 0 次保留。断开后保留最后读数并标明时效。新板没有蚂蚁的权限升级、参数写入或 MOS 控制入口。

## 发现、识别与连接顺序

1. **先看广播名称前缀**，大小写不敏感：蚂蚁 `ANT`；彦阳 `YYBMS`、`YY-`、`BT` 加数字等；嘉佰达 `JBD`、`SP`、`DB`、`XIAOXIANG` 等；极空 `JK-`、`JK_`；蓝宝 `BlueBabe`、`blue`、`lb`；陆行 `EM2APP`。
2. 名称无法确认时才使用模块提示：JBD 的 FF00；彦阳的 FEE9；极空的 **FFE0 与厂商 ID 0B65 / 4B4A 同时出现**。通用 FFE0 本身不能证明品牌。极空厂商匹配来自 aiobmsble；名称来自公开实录/设备信息，不要求用户设备一定使用默认名。
3. 无法确定品牌的候选仍可选择，但必须手动指定品牌。未知设备不再默认为蚂蚁协议，也不把错误品牌静默写入档案。扫描页提供所有已支持品牌，历史设备按档案复连；用户手动选择有覆盖权。
4. 发现家族对应服务，按特征 UUID **以及可写/可通知属性**挑选句柄。同 UUID 的读写句柄可以分开。先确认通知订阅，再等待对应只读协议返回校验正确的实时读数；只有这时新板才显示已连接。无应答继续尝试下一候选，不把 CCCD 成功当成数据可用。
5. 订阅等待给系统配对留出时间；连接失败提示当前阶段、板型、占用或配对条件。设置中的通信通道仅切换 BLE 模块，不修改板上设置。蓝宝/陆行保留既有“订阅后由仓库轮询握手”的连接流程，不能向电量计发送 ANT 探测帧。

Web Bluetooth 选择器不提供广播厂商数据和 RSSI，改名设备可手选品牌；用户选择设备后，服务与校验正确的协议回应作进一步确认。

## 本轮修复（2026-11-20）

- Android / iOS / Web 的新板连接加入真实协议探测；候选无数据时回退。彦阳特征同时支持两种写法时优先带响应写，其他设备保持其原有可用写法。Android/iOS 等待明确订阅成功，不使用固定延时假设成功。
- 彦阳签名小块 `63/4` 无回应时尝试 B 代基础块 `1/79`，仍要求其中的小端魔数 `0x4D444253` 正确。默认地址上的 B 代读取失败时尝试地址发现；发现的地址交给同一连接的后续轮询。地址发现也无回应时，在当前地址尝试旧 A。
- 非 B 签名只触发旧 A 探测；收到校验正确、串数与电压自洽的基础块才显示旧 A 读数。C 代缺少可核对的独立布局与实录，未宣称支持。HB/O2 缺可靠温度换算，隐藏温度但保留已确认的 B 代字段。
- 彦阳单次读取超时为 3 秒，持续收到分片时按进度延长且总长最多 10 秒；可选参数和身份块不阻止实时数据就绪。
- 嘉佰达先发送普通 DD 读取，免密或已系统配对的模块不会被历史凭据挡住。DD 超时或被拒绝后，使用用户提供的 6 字符密码尝试 `FF AA 15` 直接会话登录；无 MAC 也可使用。
- 对需要旧挑战流程的 JBD 模块，提供真实 MAC 后可继续 `15` 固定应用键 → `17` 随机数 → `18` 用户密码。只在明确有该用户凭据时使用；拒绝后停止该次认证，不猜密码，不改密码，不发送厂商 root 登录。
- 嘉佰达兼容大于 64 字节的扩展基本信息，按头部长度拼包。登录 15/18 内容均在日志中遮蔽。
- 极空先用实时报文结构区分 JK02 / JK04，再按软件主版本区分 JK02 24S / 32S。JK02 处理温度有效位与无效哨兵；JK04 解析独立浮点单体数据。收到分片、粘包或混入噪声时，仍只接受校验通过的帧。
- 网页三套主题接入极空并按实际字段显隐；蓝宝不显示不存在的 SOH、MOS、逐串和扩展时间。原生单路温度/汇总卡按实际项目数分列，中继名称/MAC 缺失时隐藏。电量计的功率表盘方向优先采用设备明确的充放状态，数值保留原厂符号，避免横屏把放电误标成充电。

## 只读边界与报文

彦阳只允许 FC03：代际探测 `63/4`，B 代读取 `1/79`、`80/80`、`160/81`、`240/20`，旧 A 读取 `1/47`、`48/42`、`90/22`。从机地址范围为 1–247，另允许在地址 0 发 `0/1` 发现请求。校验为 CRC16-MODBUS，响应按长度归属，只有一条请求在途。

| 读取 | 十六进制 |
| --- | --- |
| 彦阳代际 | `01 03 00 3F 00 04 74 05` |
| 彦阳基础 | `01 03 00 01 00 4F 55 FE` |
| 彦阳状态 | `01 03 00 50 00 50 45 E7` |
| 彦阳参数 | `01 03 00 A0 00 51 84 14` |
| 彦阳身份 | `01 03 00 F0 00 14 45 F6` |
| JBD 基础 | `DD A5 03 00 FF FD 77` |
| JBD 单体 | `DD A5 04 00 FF FC 77` |
| JBD 型号 | `DD A5 05 00 FF FB 77` |
| JK 设备信息 | `AA 55 90 EB 97 00 00 00 00 00 00 00 00 00 00 00 00 00 00 11` |
| JK 实时 | `AA 55 90 EB 96 00 00 00 00 00 00 00 00 00 00 00 00 00 00 00 10` |

JBD 响应补码和覆盖 status + length + payload，不包含响应寄存器；payload 内的 77 不是帧边界。JK 校验是前 299 字节的 8 位累加和。JK/JBD 的电流在板协议层归一为本项目“放电正、充电负”；彦阳有明确运行状态时以该状态定向。电量计保留原厂数值符号，网页流向优先采用其明确状态。

仓库与三端发送层共同拦截不适用的控制/校准/参数写入。JBD 不发 DD5A、不进 EEPROM 工厂模式、不发送 16 改密码或 1D 厂商提权。JK 仅 96/97 读取。BLE characteristic write 用于发送读取帧，不等于修改保护板。
