## 一分钟速查

```
服务 UUID : 0000FFE0-0000-1000-8000-00805F9B34FB
写特征    : FFE1（备选 FFF3 / FFF5）
通知特征  : FFE1（备选 FFF4 / FFF6）
备用通道  : A = FFF3/FFF4（占用蓝牙屏接口）、B = FFF5/FFF6（占用充电器接口）
            两条备用通道都不支持固件升级，仅在默认通道收不到应答时临时使用

帧格式    : 7E | 地址 | 功能码 | 寄存器2B | 长度1B | 数据N | CRC16 2B | AA 55
            ↑A1=主机 C1=第二台 A0=采集芯片      ↑小端            ↑低字节在前

CRC       : CRC16-Modbus（初值 0xFFFF，多项式 0xA001），覆盖 [地址 … 数据末]
            标准算得 0x6258 → 线上写 58 62

字节序    : 所有多字节数值小端
轮询      : 每 500 ms 发 7E A1 01 00 00 F5 58 62 AA 55，设备回功能码 0x11
```

**四个最常用的报文**（已验证 CRC，可直接回放）：

| 用途 | 报文 |
|---|---|
| 读实时数据（245 字节） | `7E A1 01 00 00 F5 58 62 AA 55` |
| 读参数区（地址 104，32 字节） | `7E A1 02 68 00 20 18 65 AA 55` |
| 保存应用参数（写 flash） | `7E A1 51 07 00 00 38 E4 AA 55` |
| 校验一级密码 `12345678` | `7E A1 23 4A 01 08 31 32 33 34 35 36 37 38 DB 50 AA 55` |

**功能码记忆法**：响应功能码通常是请求功能码 **+0x10**
（`01→11` `02→12` `03→13` `04→14` `51→61` `53→63`）；写参数类 `22/23/26` 则是 **+0x20** → `42/43/46`。

## 文档约定

- 所有十六进制字节以**空格分隔**书写，如 `7E A1 01 00 00 F5 58 62 AA 55`；紧凑写法 `7EA1010000F55862AA55` 等价。
- 「数据偏移」指**数据区**内的偏移（数据区从帧的第 7 个字节开始），不是整帧偏移。
- 多字节数值默认**小端**（低字节在前）；**例外**是 AFE 命令码（`0x59` / `0x70`）与 CRC 值本身，
  详见 [第 3.1 节 寄存器字段的字节序](03-帧格式与校验.md#寄存器字段的字节序)。
- `u16` / `s16` / `u32` / `s32` 分别表示无符号/有符号 16/32 位整数。
- 缩放写作「÷1000」，表示原始整数除以 1000 得到工程量。
- 标注「★」的是实际对接中最常用的内容。
