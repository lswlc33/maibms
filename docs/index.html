FEATURES

软件特色

把官方小程序里要一层层点进去的功能，重写成一套原生应用：直连、快、干净、一眼看得清。

🌙

深色模式，为 OLED 而生

深色下底色恒为纯黑 #000000，卡片比背景亮一档分层，省电又干净；浅色为极浅灰底 + 纯白卡片。

跟随系统浅色深色记忆选择
📊

一屏尽览，信息不翻页

设备信息、MOS/均衡状态、容量、总压电流功率、单体电压、温度、趋势曲线与控制开关，全部铺在首屏。

  • 单体电压网格：最高标黄、最低标蓝、均衡带绿点
  • 保护与告警分开两栏，各带计数
  • 未连接统一显示 --，不会把“没有数据”误读成 0
✨

界面更优雅

无边框扁平卡片，只靠底色明度与 20dp 大圆角分块；悬浮式底栏，选中项用 M3 药丸指示器。

  • 进入二级页右滑入、返回原路退回
  • 全局行高按字号等比收紧，同屏多看约三成
  • 窄屏 360dp 单独复核过排版
⚡

更快、更稳

直连 BLE，冷启动即自动重连上次的设备；掉线自愈（失败退避 + 周期性切换 autoConnect）。

  • 密码按设备保存，连上后自动升权，权限回落会静默重升
  • 应答按「功能码 + 寄存器」双比对，避免把迟到应答当成结果
  • 写参数后回读校验，不会“写完什么都不显示”
🧾

分级日志，排障不求人

协议层关键信息都记在应用内（设置 → 开发者），不用每次都接 adb。

D 帧级I 操作级W 可恢复E 失败

环形缓冲 600 条，可过滤、按级别着色、一键导出为文件。

🔐

参数读写与权限

参数分组浏览与逐项编辑，写入前校验范围与倍率；1~2 级只读、3 级及以上可写，顶栏有权限指示。

  • 控制命令含高危二次确认（需输入“确认”）
  • 各等级密码按设备保存，保存时直接向设备校验
  • 通信通道可手动切默认 / 备用 A / 备用 B，并按设备记住

Android：直接安装

最低支持 Android 8.0（API 26）。已用发布密钥签名，正式版与测试版同一密钥、可互相覆盖升级；首次启动会申请「附近的设备」权限用于扫描保护板。

iOS：未签名 ipa，需自签安装

用 Sideloadly / 爱思助手 / AltStore 以你的 Apple ID 自签后安装。免费 Apple ID 签名 7 天过期，到期重签即可；首次启动需在「设置 → 通用 → VPN与设备管理」信任证书。

ABOUT

关于这个软件

📴

核心功能全程离线

数据只在手机与保护板之间流转，不采集、不上传。唯一的联网行为是「检查更新」——只读 GitHub Releases 公开接口，连不上时自动走国内镜像回退。

🧩

多端复用

协议解析、数据层与全部界面用 Kotlin Multiplatform + Compose 一次编写，Android / iOS / 桌面三端复用；蓝牙与 App 外壳按平台各实现一份。

📜

开源 · MIT

源码在 GitHub 开放，采用 MIT 许可证。非官方项目，与保护板厂商无任何关联；协议实现来自对设备通信的观察与逆向分析。
