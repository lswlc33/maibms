横屏仪表：双盘一芯

横屏不再是竖屏卡片的重排，而是一块全新绘制的仪表总成：左右两只圆形表盘 （油车「车速 + 转速」的经典对位），中央是新能源车风格的电池芯区（SOC 大字、分段电量条、 充放电剩余、指示灯排）。整面恒深色，一眼读数，无滚动、无卡片。

触发 宽 ≥600dp 自动 基准画布 914 × 412dp 实现 Compose Canvas · 零新依赖 面漆 恒深色（汽车仪表惯例） 竖屏 维持现状不变

设计定位 从油车与新能源仪表各借什么

BMS 最常看的三个量是电压、电流、SOC——正好对上油车仪表的构图（左盘 + 右盘 + 中央行车屏） 与新能源仪表的语义（功率表充放双向、分段电量条）。颜色语义沿用卡3 换挡条已定稿的三色 （节能绿 / 均衡蓝 / 运动红），用户不用学第二套颜色。

双盘规格 270° 扫弧 · 开口朝下 · Canvas 绘制

左盘 · 总电压（油车「车速位」）右盘 · 电流（油车「转速位」= NEV 功率表）
扫弧270°，135° → 405°（开口朝下，指针竖直向上 = 盘面正中）；刻度半径约取盘面短边的 42%
量程 串数 × 单体窗口 2.5~4.5V（21 串 → 52.5~94.5V）。串数来自实时帧 cellCount，化学窗口三元锂默认，后面可按电池类型校准 ±(末档阶梯功率 ÷ 标称电压) 取整到 10A（5000W÷88V≈57A → ±60A）。量程跟功率阶梯走：用户调阶梯，盘面自动改口径——与卡3 换挡条同一套配置
刻度 主刻度 5V 一根（数字 10V 一标：60/70/80/90），副刻度 1V 主刻度 10A 一根（数字标 20A 一标：-40/-20/0/+20/+40），副刻度 2A；0 位加粗
色区弧（贴外缘，4dp 弧带） 红区：> 过充保护电压（参数区 addr 0，4.30V/串 × 21 = 90.3V）到盘端；< 过放保护电压再画一段琥珀区（参数区 addr 2） 充电半区 0 → -副档位电流 整条绿；放电半区 0 → 末档按阶梯分段：1 档绿 / 2 档蓝 / 3 档红（按当前电压折算 A，参数变更即重画）
盘心数字 85.24V 26sp 等宽 + 「总电压」9.5sp 灰字（数字在指针根部下方，指针不遮字） +12.4A 26sp 等宽 + 功率小字 1.09kW（充电时 A 为负、kW 取绝对值标「充电」）
指针单色亮白 3dp 针 + 中心圆盖；值变化 180ms 缓动（与卡3 填充动画同参数）。未连接时指针停左端（-30° 位）

中央芯区 SOC · 电池条 · 剩余时间 · 灯排

  • SOC 大字：48~52sp，旁边挂状态章（放电=绿 / 充电=青 / 待机=灰，取实时帧 battState）。
  • 分段电池条：10 段等宽，亮段数 = round(SOC/10)；段色绿，SOC<15% 整条转红（与卡1 低电红一致）。 充电中条上方亮 ⚡ 小字；条端再画正负极小凸头（电池符号感）由 P1 评估是否保留。
  • 剩余时间：充电剩余 / 放电剩余 两枚小字（刚上线的扩展段功能），0=未报 显示 --；中央区是它在全应用的 C 位。
  • 指示灯排：圆形 LED + 9.5sp 字，灭灯一律同一暗灰。点亮条件见下表——全部来自已有状态位，不需要新数据。

顶条/底条：顶条=设备名 + 连接点 + 权限 + 运行时间 + 「配置 ›」「设置 ›」两个文字按钮 （横屏仪表不设底栏，导航全在这）；底条=单体最高/最低（带串号）、压差、平均、MOS 温度、剩余/总容量、 循环容量、告警文字（琥珀）。一行等宽数字，全是 BmsStatus 现成字段。

边界态 未连接 / 充电中 / 告警 / 无扩展段

状态仪表表现
未连接 / 无数据双针停左端、盘心数字 --、SOC 大字 --、电量条全灰不亮段、六灯全灭、底条数字全 --；顶条连接点转灰，设备名保留记忆名
充电中（A<0）电流针进左半绿区，盘心 -12.4A，kW 位标「充电 1.09kW」；状态章转青「充电」；电池条亮 ⚡；充电剩余若有值则替换 --
有告警 / 保护对应灯点亮；底条尾部告警文字琥珀（保护红）；已有告警详情弹窗入口暂不进仪表（点灯无动作，P2 再议）
无扩展段固件剩余时间两枚显示 --（与卡3 现行为一致），其余不受影响
失联（数据停流）沿用现有 stalled 判定：连接灯转琥珀，数值冻结最后一拍（不归零），顶条加「失联」字样

实现映射与 QA 全部 commonMain，零新依赖

  • 新文件 ui/ClusterDashboard.kt：LandscapeCluster(status, onOpenConfig, onOpenSettings)。 表盘 = Canvas：drawArc 画轨/色区/红区，rotate+drawLine 画刻度与指针， TextMeasurer 画刻度数字；盘心数字与中央芯区用普通 Text 叠 Box。指针角度映射、刻度生成、量程折算写成纯函数进 PowerGaugeMath.kt，同步 PowerStagesTest 风格单测（角度单调、红区边界、量程取整）。
  • 接线：DashboardScreen 顶层 BoxWithConstraints，宽 ≥600dp 渲染 LandscapeCluster，否则现有竖屏 Column； 「配置/设置」两个回调从 App() 传入（与 onOpenScan 同路）。现有竖屏布局一行不改。
  • 数据：全部来自 BmsStatus 现有字段 + ParamTable（过充/过放保护电压）+ AppStore.powerStagesW（电流盘量程与分区）+ cells.size（串数）。 不动协议层、不加轮询。
  • QA：ShotMain 的 SHOT_SIZE 扩展 WxH 格式，914x411 出横屏亮/暗档 （仪表面恒深色，主要验顶条/底条与页面边缘）；场景用 72114 预设 + 未连接空态两张。MuMu 真机旋转复验。
  • 分期：P1=本蓝图全量；P2=其余页面宽屏 max-width 居中、告警灯点击进详情；P3=全屏仪表模式（隐藏顶/底条与系统栏，车载支架终态）—— 本布局顶条薄、无底栏，P3 只需加沉浸式开关，不动构图。
